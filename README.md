# Zephyr Core

Zephyr is the settlement core of the payments platform.  The repository keeps
two long-lived revisions:

* `main` - the baseline snapshot that is currently in production.
* `release/2.3.0` - the release-candidate refactor that is being prepared for
  rollout.

Security findings raised against the service are tracked in
`SECURITY_BACKLOG.md`; each finding is anchored to the source line that
carries the matching marker comment.
